# Quantum-Hypercube
This repository contains software produced by [A. Kydros](https://orcid.org/0009-0009-5278-5480) and [K. Prousalis](https://orcid.org/0000-0002-6810-1719) in
conducting research on multi-dimensional quantum images and the quantum cycle shift image transformation.

The included scripts ran locally on Python version 3.12.10, using Qiskit 1.3.3 and Qiskit Aer 0.17.2.

## Backwards Compatiblity Statement
This repository promises strict backwards compatibility in all its changes and code refactors, with regards to experiment outputs. Any and all changes preserve
all results absolutely in the format that they were published, be that text, plots, colors, symbols, etc.
